# Prototype benchmark

`models-dashboard-bench` is represented on disk as `benchmarks/proto-bench`. It tests the protocol with a small offline model-runs dashboard before large benchmarks are committed.

The baseline draft asks a candidate to build a responsive static dashboard from fictional JSON. The result contract is `result/index.html`, `styles.css`, and `app.js`. No network, packages, framework, or external asset is required.

Use it to verify drafting, freezing, single preparation, parallel preparation, manual launch, task discovery, finalization, cleanup warnings, exact-task analytics, and aggregate refresh. Do not treat prototype outcomes as production model rankings.
